# Bootcamp-de-Machine-Learning-Human-Segmentation-Dataset

Este projeto explora diferentes abordagens para segmentação de pessoas em vídeos de dança do TikTok. Foram avaliados três métodos principais:

1. FastSAM - Segmentação zero-shot em tempo real
2. YOLOv8 Segmentação - Modelo treinado especificamente para o dataset
3. YOLOv8 + OpenCV - Refinamento das máscaras geradas
